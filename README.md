Цей репозиторій містить рішення задачі передбачення відтоку клієнтів банку з використанням моделі Decision Tree 🌳.

## 🧠 Опис проєкту

📌 **Мета:** Побудова класифікаційної моделі, яка передбачає, чи залишить клієнт банк (відтік клієнта - churn) 🏦❌.

📊 **Дані:** Використовуються змагання на Kaggle — [Bank Customer Churn Prediction (DLU Course)](https://www.kaggle.com/t/7c080c5d8ec64364a93cf4e8f880b6a0) 💻🏁

## 🔧 Основні завдання проєкту

### Завдання 1: Модуляризація коду
- Створення модуля `process_bank_churn.py` з функціями для обробки даних
- Реалізація функції `preprocess_data()` для тренувальних даних з параметрами:
  - Видалення непотрібних колонок (CustomerId, Surname, id)
  - Кодування категоріальних ознак через OneHotEncoder
  - Опціональне масштабування числових ознак (параметр `scaler_numeric`)
  - Розбиття на тренувальну та валідаційну вибірки
- Реалізація функції `preprocess_new_data()` для обробки нових даних з використанням навчених трансформерів
- Використання typing та докстрінгів для документації коду

### Завдання 2: Базова модель Decision Tree
- Тренування Decision Tree Classifier з параметрами за замовченням (фіксований random_state=42)
- Обчислення метрики AUROC на тренувальних і валідаційних даних
- Аналіз наявності пере-/недонавчання моделі
- Візуалізація дерева до глибини 2 для аналізу найвпливовіших ознак
- Виявлено найважливіші ознаки: Age, NumOfProducts, IsActiveMember
- Створення датафрейму `importance_df` з топ-10 найвпливовіших ознак

### Завдання 3: Підбір гіперпараметрів методом Grid Search
- Експериментування з параметрами `max_depth` (5, 10, 15, 20, None)
- Експериментування з параметрами `max_leaf_nodes` (10, 50, 100, 200, 500, None)
- Пошук комбінації параметрів, що дає найвищий AUROC на валідаційній вибірці
- Аналіз балансу між точністю на тренувальній та валідаційній вибірках

### Завдання 4: Аналіз впливу глибини дерева
- Систематичне тестування моделей з max_depth від 1 до 20
- Побудова графіків залежності AUROC від глибини дерева
- Візуальне виявлення оптимальної глибини (max_depth=6)
- Аналіз точки, де починається перенавчання моделі

### Завдання 5: Створення submission файлу
- Тренування фінальної моделі з оптимальним max_depth=6
- Завантаження тестових даних змагання (test.csv)
- Застосування функції `preprocess_new_data()` для обробки тестових даних
- Генерація ймовірностей відтоку для тестових даних
- Формування файлу `submission.csv` для подання на Kaggle
- Формат submission: колонки 'id' та 'Exited' (ймовірності)
